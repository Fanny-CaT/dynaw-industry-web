# DYNAW Industry Web Platform

The DYNAW Industry Web Platform is a premium, interactive B2B dashboard for sportswear manufacturing. It serves as a digital catalogue and interactive flipbook, allowing sports teams and retailers to dynamically swatch custom fabric colors, explore manufacturing processes, and preview sublimated textures before placing bulk orders. The design emphasizes high-end aesthetics, deep user engagement, and brand intentionality.
